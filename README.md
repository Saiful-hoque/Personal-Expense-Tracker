# Personal Expense Tracker

A modern, responsive, and feature-rich **Personal Expense Tracker** web application built with **HTML5**, **Tailwind CSS**, and **JavaScript**, featuring persistent storage using `LocalStorage`.

---

##  Key Features

1. **Dashboard & Summary**
   - Real-time calculation of **Total Income**, **Total Expenses**, and **Current Balance**.
   - Automatically updates instantly when transactions are added or deleted.

2. **Add & Edit Transactions**
   - Clean form with validation for Title, Amount, Type (Income / Expense), Category, and Date.
   - Supports editing existing transactions.

3. **Transaction History & Tables**
   - Displays all records clearly in a responsive table.
   - Shows empty states when no records match the criteria.

4. **Filtering & Search (Bonus)**
   - Filter transactions by **All**, **Income**, or **Expenses**.
   - Real-time search bar to find transactions instantly by title.

5. **Data Persistence**
   - Uses browser `LocalStorage` so your financial records remain saved even after refreshing or reopening the browser.

6. **Confirmation Modal & Toast Notifications**
   - Secure deletion confirmation popup.
   - Smooth floating notification toasts for user feedback.

7. **Monthly Expense Breakdown (Bonus)**
   - Automatically tracks and displays the total expenses for the current month.

---

##  How to Run Locally

1. Download and extract the ZIP file.
2. Open `index.html` directly in any web browser (Google Chrome, Edge, Firefox, Safari).
3. No servers, build tools, or installation required!
